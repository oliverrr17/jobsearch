# JobSearch · 上海金融研究岗位工作台

在本机浏览 BOSS直聘、猎聘和脉脉的职位信息，按关键词整理上海金融研究岗位，支持筛选、去重、收藏和 CSV / JSON 导出。

工具使用 Node.js 提供本地网页，通过 Patchright 控制专用 Chrome。用户在该 Chrome 中登录；采集读取网页可见的职位列表，点击工作台中的职位标题也会复用同一浏览器的登录状态。

当前版本：**1.3.0**。已在 macOS、Node.js 20+ 与 Google Chrome 环境下验证。

## 能做什么

- 配置关键词、网站和列表批数，按顺序搜索、翻页或滚动。
- 将岗位按金融研究语境初筛，标记地点缺失、岗位类型不符等原因。
- 保存原始列表文字、职位链接、命中关键词和首次 / 最近采集时间。
- 按职位链接去重，重复采集时保留收藏及已有的有效字段。
- 暂停、继续任务，或跳过当前网站的当前关键词。
- 在已登录的工具浏览器中打开职位详情，不影响搜索标签页。
- 导出当前筛选结果、全部记录或收藏；CSV 可用 Excel / WPS 打开。

工具提供浏览和归档功能，没有自动投递、联系招聘者或发送消息的功能。

## 平台支持与验证范围

| 网站 | 当前支持 | 验证情况 |
| --- | --- | --- |
| BOSS直聘 | 上海关键词搜索、可见卡片采集、公司与地点提取、详情页共享登录 | 已验证登录后的真实列表、卡片结构和详情打开 |
| 猎聘 | 上海关键词搜索、可见卡片采集、详情打开 | 公开搜索实测识别到 40 张职位卡片 |
| 脉脉 | 可配置职位页入口、尝试定位岗位搜索框、手动采集当前页 | 入口及页面结构仍需使用者确认，尚未完成完整生产流程验证 |

三站的全部账号场景与分页流程尚未完整覆盖。网站改版可能需要更新选择器；登录、验证或访问频繁提示会让任务暂停。具体测试范围见 [VALIDATION.md](VALIDATION.md)。

## 环境要求

- Node.js **20 或更高版本**，附带 npm。
- 已安装 **Google Chrome**。程序使用 `channel: 'chrome'`，无需另下载 Chromium。
- 有图形桌面，方便在工具浏览器中完成登录或网站验证。

依赖锁定为 `patchright-core@1.64.3`，由 `package-lock.json` 固定安装版本。

## 快速开始

```bash
git clone https://github.com/oliverrr17/jobsearch.git
cd jobsearch
npm ci
npm start
```

打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)，并保持启动服务的终端运行。按 `Ctrl+C` 停止服务。

如果希望启动后自动在 macOS 浏览器打开工作台：

```bash
node launch.mjs
```

macOS 也可以在安装依赖后双击 `启动.command`。脚本优先使用当前用户已有的 Codex Node 运行时，找不到时使用系统 `node`；它不会自动安装依赖。

修改监听端口（macOS / Linux）：

```bash
JOB_SCOUT_PORT=8766 npm start
```

随后访问 `http://127.0.0.1:8766`。服务仅监听本机 `127.0.0.1`。

## 使用流程

1. 在工作台编辑关键词、选择网站与批数，点击 **保存配置**。
2. 点击对应网站的 **打开并登录**，在工具创建的 Chrome 中完成登录。
3. 回到工作台点击 **开始批量浏览**。任务按网站、关键词、批次顺序执行。
4. 遇到登录、验证或页面识别问题时，查看状态及浏览记录；在工具 Chrome 中处理后点击 **继续**。
5. 点击职位标题打开详情；需要进一步比较的岗位可以收藏。
6. 选择 **匹配岗位 / 全部采集 / 已收藏**，可再按公司或职位文字搜索，然后导出。

**开始批量浏览**会建立新任务队列；已有暂停任务应使用**继续**。岗位记录保留在本机，重新搜索时按链接去重。

### 登录与详情打开

工具 Chrome 的登录状态与工作台所在的普通浏览器相互独立。请从工作台点击**职位标题**，详情会在工具 Chrome 的独立标签页中打开。再次点击同一个职位会切回已有详情页。

**在当前浏览器手动打开**链接仅供普通浏览，不会接入工具的采集会话。CSV / JSON 中导出的普通网址也由打开文件的浏览器处理；该浏览器可能需要单独登录。

### 手动采集与脉脉入口

如果某站的自动搜索或页面结构未被识别，可以在该站的工具标签页中手动进入搜索结果，再点击 **采集当前页**。

脉脉可能将职位入口重定向到社区或登录页。请先在工具 Chrome 中进入实际的职位搜索页面，必要时修改 **脉脉职位页入口**。无法定位搜索框时会暂停，保留已采集记录和任务进度。

## 默认配置与筛选规则

| 配置 | 默认值 / 范围 |
| --- | --- |
| 城市 | 当前固定为上海；BOSS、猎聘使用各自的上海城市参数 |
| 关键词 | 机器人研究员、具身智能研究员、机械行业研究员、高端制造研究员、买方研究员、行业研究员 |
| 关键词数量 | 最多 15 个，自动去重 |
| 网站 | 默认选择 BOSS、猎聘、脉脉 |
| 每个关键词的批数 | 默认 2，允许 1–5 |
| 浏览等待 | 默认 10 秒，下限 10 秒、上限 30 秒 |
| 优先金融研究岗位 | 默认开启 |
| 排除实习与校招 | 默认开启 |

“批”表示一次列表采集，后续通过下一页或滚动加载更多；具体行为取决于网站。

匹配规则基于职位标题、金融相关词和地点文字。缺少地点的记录标记为“待确认”，可以在“全部采集”中查看。筛选属于规则初筛，仍需结合原文和详情判断岗位是否适合。

公司或薪酬未能识别时保留空值。BOSS 的匿名公司描述按网站原文保留；部分薪酬使用自定义字体编码，目前不自动推测其数字。

默认配置与规则在 [core.mjs](core.mjs)，工作台可修改关键词、网站、批数、筛选开关和脉脉入口。

## 本地数据

| 路径 | 用途 |
| --- | --- |
| `data/state.json` | 配置、岗位记录、收藏、任务队列及日志 |
| `data/browser-profile/` | 工具专用 Chrome 的浏览器资料与登录状态 |
| `data/state.before-v1.3.json` | 首次补全旧版 BOSS 公司字段前的备份，按需生成 |
| `artifacts/` | 手动测试生成的截图和诊断结果 |

更新代码时保留 `data/`。备份数据前先停止服务，避免复制到写入中的状态文件。

上述本地目录以及下载的参考源码 `references/`、依赖目录 `node_modules/` 均被 `.gitignore` 排除。仓库只包含程序、文档、测试和依赖锁文件；不会预置用户登录资料或岗位记录。

## 测试

安装 Chrome 和依赖后运行：

```bash
npm test
```

当前有 **21 项回归测试**，包括搜索参数、域名限制、筛选、去重与收藏、CSV 转义、DOM 提取、公司字段恢复、登录会话共享、详情页复用、跳转保护和桌面 / 移动界面。测试使用合成页面和合成 Cookie，不请求招聘网站。

以下检查会访问真实网站，需手动运行：

```bash
# 使用独立临时浏览器资料检查 BOSS / 猎聘入口稳定性及猎聘搜索
node test/live-browser.mjs
```

## 代码结构

| 文件 | 职责 |
| --- | --- |
| [server.mjs](server.mjs) | 本地 HTTP 接口、浏览器上下文、任务执行和状态保存 |
| [core.mjs](core.mjs) | 搜索地址、可见卡片提取、字段恢复、筛选、合并与导出 |
| [browser.mjs](browser.mjs) | 加载固定版本的 Patchright 驱动 |
| [navigation.mjs](navigation.mjs) | 登录入口、重复点击合并、跳转保护与访问状态识别 |
| [job-pages.mjs](job-pages.mjs) | 校验详情地址，在搜索会话中复用详情标签页 |
| [public/](public/) | 工作台 HTML、CSS 和浏览器端逻辑 |
| [launch.mjs](launch.mjs) / [启动.command](启动.command) | 启动或打开已有本地服务 |
| [test/](test/) | 离线回归与手动实站检查 |

服务端接收关键词和操作，驱动专用 Chrome 访问列表页，将提取的数据筛选、合并后写入本地状态文件；工作台定期读取状态并展示结果。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 点击外部网址后显示未登录 | 从工作台点击职位标题，以复用工具 Chrome 的登录状态 |
| 浏览器窗口被关闭 | 点击“打开并登录”重新打开，再继续任务 |
| 页面要求验证或提示访问频繁 | 任务会暂停；在工具 Chrome 查看提示并处理后继续 |
| 页面为空白或连续跳转 | 查看状态和日志；需要重新开始登录时点击“重新进入登录页”，避免连续重试 |
| 没有匹配结果 | 切到“全部采集”查看筛选原因，确认是否进入了职位列表 |
| 公司仍是匿名描述 | 按网站原文保留，程序不会推测真实公司名称 |
| 缺少浏览器驱动 | 在仓库目录运行 `npm ci` |
| 找不到 Chrome | 安装 Google Chrome 后重试 |
| 端口 8765 被占用 | 使用 `JOB_SCOUT_PORT` 指定其他端口 |
